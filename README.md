# ITDCHAT
Чат для итд.com версия 2

# Как установить.

1. Скачать расширение Tampermonkey
2. перейти на [browser://extensions/] для яндекса и [chrome://extensions] для хрома, там включть Tampermonkey
3. нажать на сведения, и поставить "Разрешить пользовательские скрипты"
4. Скачать [chatModule.js]([https://raw.githubusercontent.com/EpsilonRationes/ITDCHAT/refs/heads/main/ITDCHAT.txt](https://raw.githubusercontent.com/EpsilonRationes/ITDCHAT/refs/heads/main/chatModule.js)) ctrl + s, или кнопка в браузере.
5. Открыть Tampermonkey перейти в утилиты, нажать экспорт из файла и выбрать ITDCHAT.txt

Если у вас андроид, можно скачать приолжение Tampermonkey, или firefox он поддерживает расширения.

# Насколько безопасно?

Главная сложность в добалвении чатов в итд это хранение и передча ключей шифрования, это расширение никуда не передаёт ключи, они хранятся локально, из-за чего главная сложность пропадает. Никто посторонний не сможет прочитать сообщения.  

# Важно!

Личка работает через комменатрии у вас не должно быть бана на написание комментариев.

Регистрация — это создание поста у вас не должно быть бана на посты.

Включите уведомления для ответов на комментарии, чтобы сообщения приходили сразу без обновления страницы.

Подписка на [@itd_chat](https://итд.com/@itd_chat) необходима, это приватный пользователь. 

# Удаление сообщений

Сообщения нельзя удалить, они хранятся локально у каждого.

# Как работает

Перейдите в профиль любого кто установил расширение, можно посмотреть на стене [@itd_chat](https://итд.com/@itd_chat) там появиться кнопка `Написать`. Расширение не должно быть всё время активно, после того как создан пост регистрации расширение нужно только для расшифровки сообщений, что можно сделать в любове время.

# Где хранятся чаты

Чаты храняться локально, полученные сообщения под постом на стене [@itd_chat](https://итд.com/@itd_chat).

# Шифрование

Используется асимметричное шифрование. Закрытй ключь хранятся локально в браузере, никуде не передаются, в случае потери восстановить невозможно. 

Хранятся данные в localstorage вашего браузера, обратите внимание, что на некоторых устройствах данные могут удалться если не использовать сайт более 7 дней.

Сообщения от расширения отображаются точно так же как и обычные уведомления итд с поментой ответ на комментарий, они негде не хранятся и удаляются при перезагрузке страницы.
